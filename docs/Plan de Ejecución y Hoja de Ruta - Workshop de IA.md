# **PLAN ESTRATÉGICO Y MANIFESTO DE EJECUCIÓN**

## **Onboarding Pre-Workshop y Construcción de Hojas de Ruta de IA**

## **1\. RESUMEN EJECUTIVO Y OBJETIVOS**

### **1.1 Objetivo General**

Diseñar, estructurar y ejecutar una estrategia de onboarding pre-workshop rigurosa que garantice que el 100% de los asistentes (tanto empresas como profesionales independientes) lleguen al evento principal con:

> * Su entorno técnico (*workspace*) completamente configurado e instalado (Zero Friction).  
> * Un caso de uso de negocio real, validado y delimitado.  
> * Una hoja de ruta personalizada de IA dividida por empresa/roles o profesión/tareas.

### **1.2 Filosofía del Workshop**

> * **Principio de Cero Fricción:** En la sesión presencial/sincrónica del workshop no se pierde tiempo instalando software, abriendo cuentas o decidiendo "qué proyecto hacer". Todo eso queda resuelto en la fase pre-workshop.  
> * **100% Enfoque Práctico:** La teoría queda reducida al mínimo indispensable. Toda la interacción gira en torno a resolver problemas concretos de un negocio.  
> * **Obligatoriedad de Caso Real:** Queda prohibido trabajar con ejemplos hipotéticos o ficticios. Todo participante debe intervenir sobre un proceso operativo real.

### **2.1 Segmento A: Empresas**

> * **Criterio:** Organizaciones, startups o PYMEs que inscriben a uno o varios miembros de su equipo.  
> * **Requisito de Infraestructura:** Identificar de forma temprana la cantidad exacta de participantes y computadoras físicas que utilizarán.  
> * **Estrategia de Workspace:** Crear una estructura base para la empresa y replicar la configuración técnica y la hoja de ruta para cada integrante según su rol (ej. Marketing, Ventas, Operaciones, Desarrollo).

### **2.2 Segmento B: Participantes Individuales**

> * **Criterio:** Profesionales, freelancers, consultores o empleados que asisten por cuenta propia.  
> * **Política de Caso de Uso Real:**  
  * **Con proyecto/emprendimiento:** Trabajan sobre su propio negocio o servicio.  
  * **Sin emprendimiento propio:** **REQUISITO OBLIGATORIO.** Deben conseguir un caso de uso real antes de la Llamada 2\. Se les asignará el rol de *"Consultor de IA Junior"* y deberán aplicar lo aprendido al negocio de un amigo, familiar o cliente. Queda totalmente descartado el uso de "proyectos ficticios".

## **3\. STACK TECNOLÓGICO Y LOGÍSTICA DE HARDWARE**

### **3.1 Software e Instalaciones (Zero Friction)**

Todo el software debe estar instalado, configurado y testeado antes de finalizar la Llamada 1\.

> * **Ambientes de Desarrollo y Editores:**  
  * **Node.js:** Versión LTS recomendada para ejecución de scripts y herramientas.  
  * **GO (Golang):** Instalación del entorno del lenguaje para microservicios/CLI.  
  * **Git:** Control de versiones y clonación de repositorios.  
  * **Visual Studio Code:** Editor principal con extensiones sugeridas (Tailwind, Python, JavaScript/TypeScript, GitLens).  
  * **OpenCode:** Herramientas para desarrollo e integración.  
> * **Plataformas y Cuentas Requeridas:**  
  1. **Google Account:** Autenticación unificada y herramientas complementarias.  
  2. **Nvidia Account:** Acceso a servicios de cómputo/APIs.  
  3. **Vercel Account:** Despliegue de aplicaciones y prototipos.  
  4. **GitHub Account:** Gestión de código y repositorios.  
  5. **Highfield ($25 USD):** Plataforma/Servicio específico para infraestructura.  
  6. **Suscripción a LLMs ($20 USD/mes \- Opcional pero Recomendado):**  
     * Claude Pro o ChatGPT Plus.  
     * *Nota estratégica:* Se demostrará el uso de herramientas gratuitas, pero se recomendará enfáticamente contar con al menos una cuenta de pago como complemento clave para trabajo profesional.

### **3.2 Logística Física (Kit de Supervivencia)**

Instrucción explícita que se enviará en todos los comunicados pre-workshop:

> * **Notebook / Laptop:** Con permisos de administrador para instalar software.  
> * **Cargador original:** Indispensable para jornadas de uso intensivo.  
> * **Alargue / Zapatilla eléctrica:** Cada asistente debe garantizar su propia extensión de energía para asegurar autonomía en el espacio de trabajo.

### **4.1 Primera Llamada: Bienvenida Grupal y Setup Técnico**

> * **Modalidad:** Sesión sincrónica grupal.  
> * **Duración estimada:** 60 \- 90 minutos.  
> * **Agenda y Contenidos:**  
  1. **Bienvenida y Filosofía:** Presentación de las reglas del workshop, el enfoque práctico y el compromiso requerido.  
  2. **Explicación del Cronograma:** Fechas clave, metodología de trabajo y dinámicas de soporte.  
  3. **Live Setup (Taller de Instalación en Vivo):**  
     * Paso a paso guiado para descargar e instalar Node.js, GO, Git, VS Code y OpenCode.  
     * Resolución de errores de variables de entorno y compatibilidad en vivo.  
  4. **Creación Masiva de Cuentas:** Registro y verificación en Google, Nvidia, Vercel, GitHub y Highfield.  
  5. **Análisis de Modelos (Pagas vs. Gratis):** Evaluación de presupuesto de cada asistente para decidir si trabajarán con modelos open-source/gratuitos o con suscripciones de $20 USD (Claude/ChatGPT).

### **4.2 Segunda Llamada: Diagnóstico Individual / Empresa y Hoja de Ruta**

> * **Modalidad:** Reunión individual (para participantes independientes) o por equipo (para empresas).  
> * **Duración estimada:** 30 \- 45 minutos por sesión.  
> * **Agenda y Contenidos:**  
  1. **Revisión del Documento de Ejemplo:** Mostrar una hoja de ruta de referencia para alinear expectativas sobre los entregables.  
  2. **Análisis del Perfil:**  
     * **Si es Empresa:** Mapear la cantidad de participantes, definir la jerarquía de roles (ej. CEO, Marketing, Ops) y segmentar los procesos críticos a intervenir con IA. Replicar el workspace para cada persona.  
     * **Si es Individual:** Analizar su profesión, especialidad y rutina diaria de tareas.  
  3. **Validación Definitiva del Caso de Uso Real:** Confirmar el problema concreto a resolver. Si el asistente individual no tiene empresa, validar la empresa o emprendimiento del tercero elegido.  
  4. **Construcción de la Hoja de Ruta Personalizada:**  
     * Matriz de: \[Rol\] \-\> \[Profesión\] \-\> \[Tareas Clave\] \-\> \[Herramientas de IA\] \-\> \[Caso de Uso Workshop\].
